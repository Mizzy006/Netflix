# Netflix Titles EDA

This project performs an exploratory data analysis (EDA) on Netflix’s catalog of movies and TV shows using Python. It aims to uncover insights about the platform's content distribution by type, genre, rating, release year, and country.

## Dataset

- **Source:** [Netflix Titles on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **File Used:** `netflix_titles.csv`
- Contains information on 8,800+ titles available on Netflix including:
- Title
- Director
- Cast
- Country
- Rating
- Genre
- Date Added
- Duration

## Objectives

- Understand the structure of Netflix's content
- Visualize the distribution of movies vs TV shows
- Explore content ratings and genres
- Analyze content trends over time
- Identify top-producing countries
- Examine missing data and perform minor preprocessing

## Key Insights

- **Movies** make up the majority of Netflix’s catalog.
- **TV-MA** and **TV-14** are the most common content ratings.
- The **United States** and **India** dominate content production.
- **Dramas**, **comedies**, and **documentaries** are top genres.
- Most content has been added between **2015 and 2021**.
